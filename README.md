# MindfulClassroom | Educational Focus & Regulation Platform

An interactive classroom mindfulness and focus companion engineered for instructional settings. Designed to support student emotional regulation, pre-assessment decompression, and transitions between active learning periods.

**Live Deployment:** https://alexysgomez27.github.io/mindful-classroom-app/

---

## Core Features

* **Evidence-Based Breathing Protocols:**
  * **Box Breathing (4-4-4-4):** Equal-cadence regulation for autonomic nervous system stabilization.
  * **Calm Protocol (4-7-8):** Extended exhalation rhythm to reduce acute stress and heart rate.
  * **Quick Focus (3-3):** Rapid mental reset between lecture segments and independent work.
* **Web Audio API Sound Engine:** Procedurally synthesizes clean sine and triangle audio cues for transition markers without external audio file dependencies.
* **Dynamic Visual Pacer:** Scalable CSS keyframe visualizer calibrated to precise inhalation/exhalation durations.
* **Telemetry & Session Tracking:** Real-time client-side cycle counter tracking completed regulation rounds during a session.

---

## Technical Stack

* **Frontend:** Semantic HTML5, CSS3, Tailwind CSS
* **Scripting:** Modular JavaScript (ES6+)
* **Audio Synthesis:** Web Audio API (native browser audio contexts and oscillators)
